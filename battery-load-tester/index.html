Project Overview

For my senior design project, I worked with two other students to design and build an automated battery load tester capable of applying up to 500 A to multicell battery packs. The load uses a stepper motor to compress a carbon pile, where compressing the carbon disks reduces their resistance and increases the load current. A current-sensing feedback network provides negative feedback to adjust the stepper motor position until the load current matches the user-programmed setpoint. An AVR microcontroller manages the control system, measurements, and user interface, while a Python PC application provides remote control and data collection. An electronic load was also used to calibrate an analog ammeter, providing both analog and digital current readouts.
