Project Overview

I designed a programmable benchtop power supply with a 0–24 V output and a 0–3 A current limit. I divided the design into separate power and controller modules. The power module combines a synchronous buck converter, preregulator, and parallel linear regulators, with diode-based feedback for automatic constant-voltage and constant-current operation. I used an STM32 microcontroller and DAC to control the output voltage and current limit. An on-board status LCD reports back the measured output voltage and current while a USB-to-UART bridge is used to interface with a remote PC GUI for a more flexible user interface.

Power Supply Module

  • Converts AC input to a 24 V DC output
  • DC-DC step-down preregulator
  • Parallel 1.5 A LDO regulators
  • Constant-voltage and constant-current output control
